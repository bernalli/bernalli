# Samuele

In development, not yet public:

- **Minerva** — a self-custodial EVM smart wallet for iOS.
- **glaux** — a smart account with the same address on every EVM chain and no seed phrase.

Public:

- [TopNV](https://github.com/bernalli/TopNV) — blends the MacBook notch into a black menu bar and rounds the display corners.
- [monoPods](https://github.com/bernalli/monoPods) — a macOS app that switches audio to mono with one AirPod in and back to stereo with two.
- [parcel-tracker-bot](https://github.com/bernalli/parcel-tracker-bot) — tracks parcels through Telegram.
- [price-tracker-bot](https://github.com/bernalli/price-tracker-bot) — sends Telegram alerts when product prices drop.
- [attest](https://github.com/bernalli/attest) — defines a format for signed purchase receipts that anyone can verify offline.
