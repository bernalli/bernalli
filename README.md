Public projects:

- [parcel-tracker-bot](https://github.com/bernalli/parcel-tracker-bot) — tracks parcels through Telegram.
- [price-tracker-bot](https://github.com/bernalli/price-tracker-bot) — sends Telegram alerts when product prices drop.
